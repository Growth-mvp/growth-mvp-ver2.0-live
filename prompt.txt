## 修正内容

### 問題（第2ラウンド）
```
ReferenceError: strategyData is not defined
```

### 原因分析
1. 前回の departments 修正で以下のコードを追加：
   ```typescript
   const departments = Array.isArray(strategyData?.departments)
     ? strategyData.departments
     : ...
   ```

2. しかし、POST 関数スコープに strategyData が存在しない
   → ReferenceError: strategyData is not defined

3. 同時に portfolioEntries も未定義
   → hasStage4Context で参照していたが定義されていない

### 修正方法
不要な参照を削除し、既に定義されている変数から判定に変更：

```typescript
// ★ STAGE2では部門情報は必須ではないため、businessSegments から判定
const hasStage3Context = Array.isArray(businessSegments) && businessSegments.length > 0;
const hasStage4Context = (normalizedPortfolio?.businesses?.length ?? 0) > 0;
```

### 設計判断
- departments 参照を削除（POST 関数に strategyData がないため）
- businessSegments で hasStage3Context を判定（ユーザー入力からの値）
- normalizedPortfolio.businesses で hasStage4Context を判定（既に正規化済み）
- STAGE2では部門情報は必須ではないため、この判定で十分

### 一括確認結果
✅ npm run build 成功
