      ...state.stage3_strategy_bridge,

2. serverDataをstoreに反映する時も旧形式に戻さない

保存後にSupabaseから返ってきた serverData を store に戻す処理がある場合、そこでも strategicCore を落とさないでください。

特にこのログを確認してください：

serverData bridge keys: Array(5)

期待値は最低でも以下です：

[
  'keyThemes',
  'departmentIssues',
  'kpiCriteria',
  'commonBehaviorChanges',
  'strategicCore',
  'departmentTranslationRules',
  'generatedAt'
]

もし Array(5) しかないなら、保存payloadかDB返却後のnormalizeで落ちています。

3. autosaveで旧bridgeを保存しない

リロード直後にautosaveが走り、旧形式bridgeでDBを上書きしている可能性があります。

以下のガードを入れてください。

const existingBridge = get().stage3_strategy_bridge;

if (
  existingBridge?.strategicCore &&
  payload.stage3_strategy_bridge &&
  !payload.stage3_strategy_bridge.strategicCore
) {
  console.warn('[STAGE3 bridge save guard] blocked downgrade of strategicCore');
  payload.stage3_strategy_bridge = existingBridge;
}

または保存payload作成時に、必ず現在storeの完全版bridgeを優先してください。
