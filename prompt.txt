効果：

### 【2】会社切替時の strategyId リセット（store/strategyStore.ts）

```typescript
setCompanyScope: (id) =>
  set((s) => {

```

効果：
- ✅ 会社切替時に古い strategyId を削除
- ✅ 新会社でハイドレート時に新しい strategyId を取得

### 【3】データフロー確認

**正常フロー：**
1. ユーザー会社選択 → setCompanyScope 呼び出し
2. strategyId: undefined にリセット
3. loadAndHydrate で新会社の strategy_data をロード
4. hydrateFromFullState で新しい strategyId を設定
5. handleGenerateFinal でガード検証（両変数存在）
6. API呼び出し成功

**エラーフロー：**
1. 会社未選択 or ハイドレート未完了
2. strategyId: undefined のまま
3. handleGenerateFinal のガードで検出
4. エラーメッセージを表示
5. API呼び出しなし（過去データ保護）
