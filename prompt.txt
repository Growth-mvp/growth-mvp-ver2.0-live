いまの PowerShell コマンドは malformed syntax になっているので実行しないでください。

Windows PowerShell 互換で、以下を個別に実行してください。

cd "C:\dev\growth-mvp-ver2.0"
npm run type-check

次に、type-check の結果を確認してください。
もし既存エラーのみで今回修正ファイルに関係ない場合は、エラー全文ではなく以下だけ報告してください。

- エラー件数
- エラー発生ファイル
- 今回修正ファイルに関係するか
- build 実行可否

type-check が通る、または既存エラーで今回修正と無関係と確認できた場合のみ、次を実行してください。

npm run build
npm run lint
npm audit --omit=dev

注意：
- .env.local、secret、token、API key は表示しない
- エラー出力にsecretらしき値が含まれる場合はマスクして報告
