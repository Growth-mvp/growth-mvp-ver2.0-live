- docs/security-log/audits/2026-07-03_audit-01.md の追加
- docs/security-log/README.md の追加または更新

現在こちら側でも以下のような監査関連ファイルを作成済みです：
- Supabase schema dump

- npm auditレポート

やってほしいこと：
1. git status を確認
2. 現在のブランチ名を確認
3. ローカルに未コミット変更がないか確認
4. git log --oneline --decorate -5 で現在位置を確認
5. git fetch origin を実行
6. git status と git log --oneline --decorate --all -10 を確認
7. GitHub側に未取得コミットがあるか確認
8. 取り込み前に、衝突しそうなファイルを一覧化
   - docs/spec/
   - docs/security-log/
   - supabase/
9. 未コミット変更がなければ git pull または git merge origin/main を実行
10. conflict が出た場合は勝手に解決せず、衝突ファイルと内容を報告
11. 取り込み後、以下がローカルに存在するか確認
   - docs/spec/08-security-audit-checklist.md
   - docs/spec/09-non-functional-requirements.md
   - docs/security-log/audits/2026-07-03_audit-01.md
   - docs/security-log/review-01/
   - docs/security-log/README.md

禁止：
- git reset --hard は実行しない
- git checkout -- で変更を捨てない
- 未コミット変更を勝手に削除しない
- conflict を勝手に雑に解決しない
- .env.local を触らない
- secretを表示しない
