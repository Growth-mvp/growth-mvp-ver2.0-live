## 修正内容

### 問題
app/api/stage2/generate-final/route.ts で logInputGuard を呼ぶ際に、hasStage3Context を計算するために departments を参照していたが、当該変数が定義されていなかった。

### 原因
以下のコードで departments が未定義：
```typescript
const hasStage3Context = Array.isArray(departments) && departments.length > 0;
```

### 修正
strategyData から departments を安全に取得するコードを追加（1333-1338行目）：

```typescript
// ★ strategyData から departments を安全に取得
const departments = Array.isArray(strategyData?.departments)
  ? strategyData.departments
  : Array.isArray((strategyData as any)?.editableCascadeResult)
    ? (strategyData as any).editableCascadeResult
    : [];
```

### 設計
- strategyData.departments が存在 → それを使用
- なければ strategyData.editableCascadeResult → それを使用
- どちらもなければ [] で初期化
- STAGE2では部門情報がなくても最終ストーリー生成可能
