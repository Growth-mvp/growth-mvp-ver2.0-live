## 修正内容

### 原因特定
`app/stage2/page.tsx` の `handleGenerateFinal` 関数で payload 作成時に以下が存在していました：
```typescript
strategyDataId: strategyId,  // ← strategyId が未定義
```

### 修正方針
Stage2PageContent コンポーネント内で strategyId を useStrategyStore から取得：

```typescript
const strategyId = useStrategyStore((s: StrategyState) => s.strategyId);
```

### 修正内容
- **ファイル**: app/stage2/page.tsx
- **行**: 1722 に追加
- **変更**: 1行のみ

API側（stage2/generate-final/route.ts）は複数のキー名を受け入れる：

const requestedStrategyDataId = pickFirstText(
