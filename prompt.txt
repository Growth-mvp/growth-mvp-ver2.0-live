ビルドエラーが出ています。まずこれを直してください。

## エラー
`store/strategyStore.ts`

```txt
Module parse failed: Identifier 'payloadBridge' has already been declared (3298:30)

該当箇所：

const payloadBridge = payload.stage3_strategy_bridge;
const serverBridge = serverData.stage3_strategy_bridge;
const currentStoreState = get();

同じ関数/同じスコープ内で、すでに payloadBridge が宣言されているため、再宣言エラーになっています。

修正方針
方法A：既存の payloadBridge を再利用する

すでに上で宣言済みなら、下では const payloadBridge = ... を消してください。

例：

// 既存の payloadBridge が上で宣言済みなら再宣言しない
const serverBridge = serverData.stage3_strategy_bridge;
const currentStoreState = get();
方法B：変数名を変える

もし別用途なら、変数名を変えてください。

例：

const restorePayloadBridge = payload.stage3_strategy_bridge;
const restoreServerBridge = serverData.stage3_strategy_bridge;
const currentStoreState = get();

その後の参照も全部 restorePayloadBridge / restoreServerBridge に合わせてください。

注意

今回の修正では、payloadBridge がすでに保存payload確認ログなどで使われている可能性が高いです。
同じスコープに追加した復元用コードだけ、以下のように別名にするのが安全です。

const restorePayloadBridge = payload.stage3_strategy_bridge;
const restoreServerBridge = serverData.stage3_strategy_bridge;
const currentStoreState = get();

const bridgeToRestore =
  restorePayloadBridge?.strategicCore
    ? restorePayloadBridge
    : restoreServerBridge?.strategicCore
      ? restoreServerBridge
      : currentStoreState.stage3_strategy_bridge?.strategicCore
        ? currentStoreState.stage3_strategy_bridge
        : restoreServerBridge ?? restorePayloadBridge ?? currentStoreState.stage3_strategy_bridge;

ログも以下に変えてください。

console.log('[STAGE3] bridge restore after save', {
  payloadBridge_hasStrategicCore: !!restorePayloadBridge?.strategicCore,
  serverBridge_hasStrategicCore: !!restoreServerBridge?.strategicCore,
  storeNow_hasStrategicCore: !!get().stage3_strategy_bridge?.strategicCore,
});
修正後
ビルドエラーが消えること
STAGE3画面が表示されること
その後、前回の確認ログで以下になることを確認してください
[STAGE3] bridge restore after save
storeNow_hasStrategicCore: true
storeNow_bridge_keys: Array(7)

これはロジック以前にコンパイルが止まっています。  
まず **変数名を `restorePayloadBridge` に変える** のが一番安全です。
