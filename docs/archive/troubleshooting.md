# トラブルシューティング

## 一般的なエラーと対処方法

### AuthSessionMissingError

**症状**: ログイン画面に戻される、「ログイン状態が失われました」というメッセージ

**原因**:
- セッション期限切れ（24 時間）
- ブラウザの Cookie が削除された
- 複数タブで同時ログイン

**対処**:
1. 一度ログアウト（画面右上の「ログアウト」ボタン）
2. もう一度ログイン
3. それでも解決しない場合：
   - ブラウザの Cookie・キャッシュをクリア（Ctrl+Shift+Delete）
   - 別ブラウザで試す

---

### 保存が反映しない

**症状**: データを入力して保存ボタンを押したが、リロード後に元に戻っている

**原因**:
- ネットワーク接続の中断
- 「保存中...」が完了する前に別ページに遷移
- ブラウザがローカルキャッシュのみ保存

**対処**:
1. 右上に「保存中...」表示があるか確認 → 完了まで待つ
2. ページをリロード（Ctrl+R）
3. キャッシュをクリアしてリロード（Ctrl+Shift+R）
4. それでも反映しない場合：
   - CEOChat で「保存が反映していません、確認してください」と報告
   - データをコピー＆ペーストして再入力

---

### ChunkLoadError

**症状**: 「チャンク読み込みエラーが発生しました」、または画面が白い

**原因**:
- 大規模データ（数万行の CSV など）をアップロード時
- ブラウザのメモリ不足
- JavaScript ファイルの読み込み失敗

**対処**:
1. ページをリロード（Ctrl+R）
2. 数秒待機してからアクセス
3. キャッシュをクリアしてリロード（Ctrl+Shift+R）
4. 別ブラウザ（Chrome、Firefox など）で試す
5. 大規模データの場合：
   - CSV ファイルを分割（例：年度ごと）して複数回アップロード

---

### 「権限がありません」エラー

**症状**: 特定の戦略・データが見えない、編集できない

**原因**:
- ロール不足（管理者のみアクセス可など）
- 会社 ID が異なる組織のデータにアクセス
- 戦略に割り当てられていない

**対処**:
1. 自分のロール確認（画面右上 → 「アカウント」 → 「ロール」）
   - Admin: 全機能・全戦略アクセス可
   - Manager: 配下の戦略のみ編集可
   - Member: 割り当てられた戦略のみ閲覧
2. 必要な権限がない場合：
   - 会社の Admin に「○○戦略へのアクセスをください」と依頼
   - または別アカウント（Admin 権限付き）でログイン

---

### PGRST116 / JWT エラー

**症状**: API 呼び出し時に「トークンエラー」、または一部機能が動作しない

**原因**:
- API トークン期限切れ
- ネットワーク接続の問題
- サーバー側の一時的エラー

**対処**:
1. ページをリロード（Ctrl+R）
2. 1-2 分待機してから再試行
3. それでも解決しない場合：
   - ログアウト → ログイン
   - CEOChat で「API エラーが出ます」と報告

---

### データ型エラー（PostgreSQL 22P02）

**症状**: 「データ型が不正です」、数値フィールドに文字が入っているなどのエラー

**原因**:
- 数値フィールドに文字列を入力（例：「万円」「$」などの単位が入っている）
- 日付が想定フォーマットと異なる
- CSV インポート時のヘッダー名が一致していない

**対処**:
1. 入力値を確認：
   - 数値フィールド：半角数字のみ（単位・記号は不要）
   - 日付フィールド：YYYY-MM-DD 形式
   - テキストフィールド：文字数制限を超えていないか
2. CSV インポート時：
   - ヘッダー行が正確か確認（csv-format.md 参照）
   - 数値にカンマが含まれていないか確認
3. 修正後、再度入力・アップロード

## トラブルシューティング チェックリスト

以下の順番で試してください：

1. **ネットワーク確認**
   - インターネット接続は正常か？
   - VPN 接続している？

2. **ブラウザ確認**
   - 最新バージョンか？（Chrome / Firefox / Safari 等）
   - 複数タブで同時ログインしていないか？
   - Cookie・キャッシュをクリアしたか？

3. **ページリロード**
   - 通常リロード（Ctrl+R）
   - キャッシュクリア＆リロード（Ctrl+Shift+R）

4. **ログイン状態確認**
   - ログインしているか？（画面右上にユーザー名が表示されているか）
   - ログイン期限は切れていないか？（24 時間以上操作がないと期限切れ）

5. **データ確認**
   - 入力値の形式は正しいか？（数値、日付、テキスト）
   - 必須項目を入力したか？

6. **別ブラウザ・デバイス**
   - 別ブラウザで試す
   - 別デバイス（PC / タブレット）で試す

7. **サポート報告**
   - 上記で解決しない場合、CEOChat で以下を報告：
     - エラーメッセージ全文
     - どの操作でエラーが出たのか
     - ブラウザの種類・バージョン
     - ブラウザのコンソール出力（F12 → Console タブ）

## よくある質問（FAQ）

### Q: データを何度も入力するのが面倒

**A**: CSV インポート機能を使ってください（Stage 1 の「基本情報」→ CSV アップロードボタン）。テンプレート形式に従えば、一括でアップロード可能です。

### Q: AI の生成内容が納得できない

**A**: CEOChat で「もう少し具体的に」「こういう観点も含めて」と指示できます。回数制限なしで何度でも生成・修正可能です。

### Q: 複数ユーザーで同時編集したい

**A**: 会社の Admin が各ユーザーを招待し、ロールを付与することで可能。リアルタイム競合には対応していないため、編集は「交代」で行ってください。

### Q: データをエクスポートしたい

**A**: 各画面の右上「ダウンロード」ボタンで、Excel / CSV / PDF 形式で出力可能。

### Q: 過去のバージョンに戻したい

**A**: 自動バックアップ機能はありません。重要なデータは定期的にエクスポートしておくことを推奨します。
