# CSV 形式ガイド

## 対応ファイル形式

- **ファイル形式**: CSV（カンマ区切り）
- **文字コード**: UTF-8
- **拡張子**: .csv
- **ファイルサイズ**: 最大 10 MB

---

## Stage 1 財務データ CSV

Stage 1 の「基本情報」でアップロード可能です。

### 必須列

| 列名 | 説明 | 形式 | 例 |
|-----|------|------|-----|
| 年度 | 会計年度 | YYYY 形式 | 2023 |
| 売上 | 売上高 | 整数（万円） | 100000 |
| 営業利益 | 営業利益 | 整数（万円） | 15000 |
| 営業外収益 | 営業外収益等 | 整数（万円） | 500 |
| 営業外費用 | 営業外費用等 | 整数（万円） | 200 |
| 税引前当期利益 | EBIT | 整数（万円） | 15300 |

### オプション列

| 列名 | 説明 | 形式 |
|-----|------|------|
| 純資産 | 株主資本 | 整数（万円） |
| 総資産 | 総資産 | 整数（万円） |
| 有利子負債 | 借入金等 | 整数（万円） |
| 売上原価 | COGS | 整数（万円） |
| SG&A | 販売管理費 | 整数（万円） |

### 例

```
年度,売上,営業利益,営業外収益,営業外費用,税引前当期利益,純資産,総資産
2023,100000,15000,500,200,15300,300000,500000
2022,95000,14000,400,180,14220,280000,480000
2021,90000,13000,300,150,13150,260000,450000
```

### よくあるエラーと対処

| エラー | 原因 | 対処 |
|-------|------|------|
| 行が不足 | 3 年未満 | 最低 3 年分のデータが必要。不足の場合は手入力 |
| ヘッダーが認識されない | 日本語と英語が混在 | 列名を英語（Revenue, Operating Income など）または日本語（売上、営業利益）に統一 |
| 数値エラー | カンマが含まれている | 「100,000」ではなく「100000」に修正 |
| 数値エラー | 単位（万円、円など）が付いている | 「100000 万円」ではなく「100000」のみ |
| 数値エラー | 小数点がある | 「15000.5」ではなく整数「15000」か「15001」に修正 |
| 年度エラー | 年度形式が異なる | 「2023 年度」ではなく「2023」のみ、または「2023-04-01」形式 |

## 事業部別 CSV

Stage 1 の「事業部別」タブでアップロード可能です。

### 必須列

| 列名 | 説明 | 形式 |
|-----|------|------|
| 事業部 | 部門名 | テキスト（営業部、製造部など） |
| 年度 | 会計年度 | YYYY 形式 |
| 売上 | 部門売上 | 整数（万円） |
| 営業利益 | 部門営業利益 | 整数（万円） |

### 例

```
事業部,年度,売上,営業利益
営業部,2023,60000,9000
営業部,2022,57000,8500
営業部,2021,54000,8000
製造部,2023,40000,6000
製造部,2022,38000,5500
製造部,2021,36000,5000
```

## 作成方法（Excel）

### Step 1: Excel ファイルを作成

1. Excel を開く
2. 列ヘッダーを入力：`年度`, `売上`, `営業利益`, ...
3. 各行にデータを入力
4. **重要**: すべてのセルを「数値」形式に設定（右クリック → セルの書式設定 → 数値 → 小数点なし）

### Step 2: CSV で保存

1. ファイル → 名前を付けて保存
2. ファイル形式：**CSV (カンマ区切り) （.csv）**
3. ファイル名：例）`財務データ_2023.csv`
4. **文字コード確認**：UTF-8 を使用（ただし Excel が自動判定する場合がほとんど）

### 注意：Excel → CSV 変換時の自動修正

Excel はセルの形式を自自動で判定するため、以下に注意：

- 先頭の 0 が削除される可能性（例：「01 月」→「1」）
  - **対処**: 事前に セル形式を「テキスト」に設定
- タイムゾーン情報が失われることがある
  - **対処**: 日付を「YYYY-MM-DD」形式で統一

## CSV をアップロード

### Stage 1 財務データ

1. GROWTH にログイン → Stage 1 へ
2. 「基本情報」画面右上の「CSV インポート」ボタン
3. ファイルを選択 → アップロード
4. 「検証」ボタンで形式確認
5. エラーがなければ「アップロード」を確定

### よくあるエラー

| メッセージ | 対処 |
|----------|------|
| 「ヘッダーが正しくありません」 | CSV の 1 行目がヘッダーか確認。別シートから不要な行が混在していないか確認 |
| 「年度が 3 年未満です」 | 3 年分のデータ（2021、2022、2023 など）を入力 |
| 「数値が不正です」 | カンマ、単位、スペースを削除。全セルが数値形式か確認 |
| 「列が不足しています」 | 必須列（年度、売上、営業利益、税引前当期利益）が全てあるか確認 |

## トラブルシューティング

### CSV は開けるが、GROWTH でアップロードエラー

**Step 1**: ファイルを Notepad で開いて確認

```
年度,売上,営業利益,...
2023,100000,15000,...
2022,95000,14000,...
```

- カンマで正しく区切られているか？
- 不可視文字（BOM など）は入っていないか？

**Step 2**: 最初の行だけコピーして新規 CSV ファイルを作成

```
# 新規ファイルを作成
年度,売上,営業利益
2023,100000,15000
2022,95000,14000
2021,90000,13000
```

### 「ファイルが見つからない」

- ファイルパスに日本語が含まれていないか確認
- ファイルが実際に存在するか確認（エクスプローラーで確認）
- ファイルが他のアプリで開かれていないか確認

### 複数ファイルをアップロードしたい

- 1 ファイル 1 回のアップロード
- 複数の事業部データは 1 つの CSV に統合してアップロード

```
事業部,年度,売上,営業利益
営業部,2023,60000,9000
営業部,2022,57000,8500
営業部,2021,54000,8000
製造部,2023,40000,6000
製造部,2022,38000,5500
製造部,2021,36000,5000
```

## ベストプラクティス

1. **事前チェック**
   - Excel で確認し、ヘッダー・数値に誤りがないか確認
   - 3 年分のデータがあるか確認

2. **ファイル命名**
   - わかりやすい名前（例：`財務データ_2023.csv`）
   - 日本語ファイル名は避ける（ただし GROWTH はサポート）

3. **バージョン管理**
   - アップロード前に PC にバックアップ保存
   - 修正が必要な場合に備えて、元データを保持

4. **サポート連絡**
   - アップロード後、数字が正しく計算されているか確認
   - 指標値（ROIC など）が業界標準と大きく異なる場合は、ロジック確認を依頼
