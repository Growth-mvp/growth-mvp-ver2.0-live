# Stage 1: 企業価値分析

## 目的
財務データから企業価値の状態を定量化し、改善領域（課題の当たり）を掴みます。主に ROIC / WACC / PBR / 成長率 / 利益率 を確認します。

## 入力するもの（UIに存在する項目のみ【実装済み】にする）
- 【実装済み】全社PL/BS：過去2〜3年（推奨3年）
- 【実装済み】事業部別PL/BS：任意（複数事業がある場合）
- 【実装済み】スナップショット：任意（将来見立て）
- 【実装済み】PBR関連の手入力：任意/必須（現仕様に合わせて明記）

## 画面
- 【実装済み】基本情報：会社属性＋全社PL/BS入力（CSVインポート可）
- 【実装済み】事業部別：事業部PL/BS入力（任意）

## 出力（表示されるもの）
- 【実装済み】5指標の計算結果（ROIC/WACC/PBR/成長率/利益率）
- 【実装済み】改善領域の示唆（例：収益性/資本効率/成長など）
- 次：Stage2（戦略策定）へ

## よくある詰まり
- 3年分がない：2年でも可（不足分は補足/スナップショットで補う）
- CSVエラー：ヘッダー揺れ、カンマ混入、年度不足を確認（csv-format.md）
- ROICが負：営業利益が赤字、または投下資本が大きい可能性

## 参考：計算式（詳細）
- ROIC = 営業利益 × (1-実効税率) / (純資産 + 有利子負債)
- WACC = 資本コスト×資本比率 + 負債コスト×(1-実効税率)×負債比率
- PBR = 時価総額 / 純資産
- 成長率 = 過去2〜3年のCAGR（売上など）
- 利益率 = 営業利益 / 売上
