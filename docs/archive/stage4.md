# Stage 4: 実行計画策定

## 目的
Stage 3で定義した部門戦略・プロジェクト・OKRを、実行可能な計画に落とし込みます（誰が/いつまでに/何を/どうやって）。

## 入力するもの（【実装済み】のみ残す）
- 【実装済み】優先順位：プロジェクト/OKRの実行順
- 【実装済み】マイルストーン：中間成果物・期限・成功条件
- 【実装済み】担当：オーナー/関与メンバー
- 【実装済み】リソース/予算：必要工数・費用（粒度は画面項目に合わせる）
- 【実装済み】依存関係：Aの後にBなど（項目がある場合のみ）

※「タブ/ボタン/画面名」は、実UIに表示されている正式名称に合わせること。

## 出力（更新されるもの）
- Stage 4の実行計画（タイムライン/担当/予算/依存関係が揃った状態）
- 次：Stage 5で進捗入力・運用へ

## よくある詰まり（症状→対処）
- マイルストーン粒度：3〜6ヶ月なら月次、1年超なら四半期が目安
- リソースが足りない：優先順位を先に決め、上位だけ計画を確定する
- 依存関係が複雑：まず「前提になる作業」だけを2〜5個に絞って記載する

## 【計画中/検討】（必要なら）
- （計画中）ガント表示、Excel/PDF出力、最適化ボタン、依存可視化… 等
