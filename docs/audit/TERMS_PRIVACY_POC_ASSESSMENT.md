## 2. PoC 要件との差分

### PoC 実装要件

**必須項目**:
1. ✅ 法人とのNDA・PoC覚書で利用条件・データ取扱いを合意
   - **現状**: 契約文書は本リポジトリ外で管理（確認不可）
   
2. ❌ /terms に利用規約を掲載
   - **現状**: プレースホルダーのみ（正式版は掲載されていない）
   
3. ❌ /privacy にプライバシーポリシーを掲載
   - **現状**: プレースホルダーのみ（正式版は掲載されていない）
   
4. ✅ 個々のPoCユーザーについてDBへの同意履歴保存は必須としない
   - **現状**: 同意機能自体が実装されていないため、自動的に要件満たし

### 正式サービス化時の要件

**追加実装**: user_agreements テーブル、API、middleware の実装が必要
