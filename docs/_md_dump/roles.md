# ロール・権限ガイド

## GROWTH のロール体系

GROWTH では、ユーザーのロールに基づいてアクセス・編集権限が決まります。

---

## ロール一覧

### 1. Admin（管理者）

**定義**: 会社全体の戦略・メンバー・設定を管理

**権限**:
- ✓ すべての戦略の閲覧・編集
- ✓ すべてのステージ（1-6）へのアクセス
- ✓ チームメンバーの追加・削除・ロール変更
- ✓ 会社情報・API キーの設定変更
- ✓ CSV インポート・エクスポート
- ✓ AI 機能（12 問生成、シミュレーションなど）の利用

**責務**:
- チームメンバーのオンボーディング
- データ品質の確保
- 定期的なアーカイブ・バージョン管理

**例**: CEO、経営企画責任者

---

### 2. Manager（マネージャー）

**定義**: 配下の戦略・プロジェクト・チームを管理・編集

**権限**:
- ✓ 割り当てられた戦略のみ、すべてのステージへのアクセス
- ✓ 配下の戦略の編集・AI 機能利用
- ✗ 他の Manager の戦略には編集権限なし（閲覧のみ、依頼による）
- ✗ メンバー管理・ロール変更はできない
- ✗ 会社設定・API キー変更はできない

**責務**:
- チームメンバーへのコンテキスト共有
- 進捗管理・定期レビュー
- AI 生成内容の監修・修正

**例**: 事業部長、プロジェクトマネージャー

---

### 3. Member（メンバー）

**定義**: 割り当てられた戦略の閲覧・入力

**権限**:
- ✓ 割り当てられた戦略のみ、すべてのステージの「閲覧」
- ✓ Stage 5（実行支援）の進捗入力
- ✗ Stage 1-4 の編集（表示のみ）
- ✗ AI 機能の利用制限あり（進捗診断のみ）
- ✗ CSV インポート・エクスポート

**責務**:
- 割り当てられたプロジェクトの進捗入力
- 定期的な進捗報告

**例**: プロジェクトメンバー、実行チーム

## アクセス制御（RLS: Row Level Security）

### 会社（Company）

- GROWTH は複数の会社に対応
- 会社ごとに独立したデータベース領域
- 異なる会社のデータは完全に分離（アクセス不可）

**確認方法**:
- 画面右上 → 「アカウント」 → 会社名表示
- 複数会社のアカウントがある場合、切り替え可能

### 戦略（Strategy）

- 各戦略には「所有者」と「アクセス権限」がある
- Admin が戦略ごとにメンバーを割り当てる
- Member は割り当てられた戦略のみアクセス可

**確認方法**:
- トップページの「マイ戦略」に割り当てられた戦略一覧
- 権限がない戦略は表示されない

## ロール遷移・変更

### 新規ユーザーのオンボーディング

1. **Admin が新規ユーザーを招待**
   - 招待メール送信（サインアップリンク付き）
   - ユーザーが Eメール認証後、パスワード設定

2. **Admin がロール・戦略を割り当て**
   - 「メンバー」画面から追加ユーザーを検索
   - ロール（Admin/Manager/Member）を選択
   - 特定戦略へのアクセス許可

3. **ユーザーがログイン**
   - 割り当てられた戦略にアクセス可能
   - 初回は「使い方」チュートリアル表示

### ロール変更

- **Admin のみ** ロール変更可能
- 変更後、対象ユーザーには通知（メール）
- 権限が減る場合（Admin → Manager）、以前のアクセスは自動削除

**変更例**:

```
Manager → Admin（昇進）
- すべての戦略へのアクセス権を取得
- メンバー管理権限を取得

Member → Manager（昇進）
- 配下の戦略が編集可能に
- AI 機能の完全利用権を取得

Admin → Member（異動）
- アクセス権が厳格に制限
- 編集権限は削除
```

## 「権限がありません」エラーが出た場合

### 対処ステップ

**Step 1**: 自分のロールを確認
1. 画面右上 → 「アカウント」
2. 「ロール」欄を確認
3. 期待と異なる場合、Manager に報告

**Step 2**: アクセス可能な戦略を確認
1. トップページ → 「マイ戦略」
2. アクセスしたい戦略が表示されているか確認
3. 表示されない場合、Admin に「戦略 XX へのアクセス許可をください」と依頼

**Step 3**: 機能ごとの権限確認
- 上記の「権限マトリックス」で、使いたい機能がロールで利用可能か確認
- 利用できない場合：
  - ロール昇進が必要？ → Manager に昇進依頼
  - 他の Manager に手伝ってもらう？ → 該当 Manager に相談

**Step 4**: 不明な場合
- CEOChat で「こういう操作をしたいのですが権限がありません」と報告
- AI が初期診断し、Admin への連絡が必要かを判定

## ベストプラクティス

### Member とロール割り当て

1. **最小権限原則**: 必要最小限のロールを割り当てる
   - 進捗入力のみ → Member
   - 戦略編集が必要 → Manager
   - 全社管理が必要 → Admin

2. **定期的な権限見直し**
   - 異動時にロール変更
   - 不要な権限は削除
   - Admin はメンバー一覧を定期確認

3. **セキュリティ**
   - Admin ロールは厳格に管理（2-3 名に限定推奨）
   - 退職者のアカウント削除（Admin のみ）
   - API キーは定期更新

### 複数会社のアクセス

複数会社に属する場合：
1. 右上のアカウント → 「会社切り替え」
2. アクセスしたい会社を選択
3. その会社のロールと権限で操作

## FAQ

### Q: Manager が別の Manager の戦略を編集したい

**A**: 直接編集はできません。以下から選択：
- 対象 Manager に修正を依頼
- Admin に一時的に権限を変更してもらう
- Manager が別の Manager の戦略を「参照」することは可能（編集不可）

### Q: Member から Manager に昇進した場合、以前のアクセス権はどうなる？

**A**: 自動的に削除されません。Admin が明示的に設定を変更する必要があります。

### Q: ロール変更はいつ反映される？

**A**: 即座に反映。対象ユーザーは次回ログイン時から新しい権限を使用可能。

### Q: Admin が退職した場合どうする？

**A**: 後任の Admin を指定し、権限移譲。複数の Admin を推奨（相互バックアップ）。

### Q: Member で進捗入力をしている最中、誤ってデータ入力、修正権限がない

**A**: Manager に「修正をお願いします」と連絡。Manager が Stage 5 で修正・確定。
