# 組織変革ルーム・経営計画書・管理機能・保存

## 組織変革ルーム（/org-transformation・/org-transformation/shared）

組織変革ルームは、社員が感じている違和感を整理し、必要なら全社のすり合わせの場につなげる画面です。

個人の部屋では、違和感を入力したあとに共有範囲を選びます。「匿名で共有」は入力者の名前を出さず、認識のズレとして共有します。「管理者にのみ共有」（初期値）は、すり合わせの場を設定する管理者だけに入力者を共有します。「名前を出して共有」は、関係者に入力者の名前を共有したうえで、すり合わせを依頼します。

すり合わせの場を依頼するときは、STEP5で「すり合わせの場を依頼」を押し、共有範囲を選んで「この内容で認識のズレを整理する」を押します。

全社すり合わせルーム（/org-transformation/shared）では、共有された話題を一覧で見られます。話題を絞り込み、詳しく開けます。

## 経営計画書（/report）

経営計画書は、銀行向け・株主向け・社員向けの計画書にまとめて出力する画面です。

銀行向けの例では、「銀行向け経営計画書」を開き、「AI本文を生成」（作成済みのときは「AIで再生成」）で本文を作ります（管理者・管理職）。保存した計画書だけ、「Wordダウンロード」「PDFダウンロード」で出力できます。「印刷」は開いている画面を印刷します。

保存していない計画書は、Word・PDFでは出せません。「本文をコピー」と「Markdownでダウンロード」だけが使えます。数値は、トップ画面と同じ試算の結果を使います。

## 管理機能：メンバーの招待と権限（管理者）

社員を会社に招待し、権限（member・manager・admin）を決めます。管理者だけが使えます。

「管理者専用：メンバー管理」を開き、「招待管理ページ」を開きます。「メール招待」の欄に、メールアドレスを入れて権限を選び、「招待メール送信」を押します。招待は7日間有効です。

メンバーの権限は、メンバー管理の行の権限の選択欄で変えます。最後の管理者の権限は下げられません。自分自身は削除できません。管理者以外は、この画面を使えません（「管理者のみアクセスできます。」と表示されます）。

送信に失敗してリンクが表示されたときは、「リンクをコピー」で共有します。

## 保存と反映

保存の種類は画面ごとに異なります。STAGE1の会社名のように、入力すると自動で保存されるものがあります。

手動で保存するものは、STAGE4の実行計画（「計画を保存」）、STAGE6の試算条件と借入（「財務計画を保存」）、STAGE5の実績（「実績を保存」）と進捗（「進捗を保存」）です。

AIの生成結果は、利用者が採用するまで計画を置き換えません。例えば、STAGE4の「この案を使う」を押すまで、今の計画書は変わりません。

サイドバー下部には「保存済み」「保存中」「未保存の変更あり」が出ます。未保存の変更がある間は、ページを離れる前に警告が出ます。保存に失敗したときは、画面に出た理由を確認して、操作をもう一度行います。
