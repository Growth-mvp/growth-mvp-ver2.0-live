# Stage 2: 経営戦略策定

## 目的
Stage1 の分析（課題感）を踏まえ、全社の「勝ち筋」を言語化し、最終的に 1 つの統合戦略ストーリーへ落とし込みます。

## 入力するもの
- MVV（ミッション/ビジョン/バリュー）
- SWOT（強み・弱み・機会・脅威）
- 勝ち筋候補（3〜5案が目安）
- 12問への回答（仮説検証）

## 進め方（作業の順番）
1. MVV を入力（未入力でも進められる設計なら明記）
2. SWOT を入力（箇条書きでOK）
3. 勝ち筋候補を列挙（後で絞る前提でOK）
4. 12問に順に回答して、前提・根拠・やらないことまで具体化
5. 最終ストーリーを生成 → 修正 → 確定

## 出力（生成されるもの）
- 統合戦略ストーリー（文章）
- 重要ポイント（3〜5件）
- 12問の要約（前提・論点・決定事項）

## よくある詰まり
- 12問が難しい：まず「現状→課題→仮説→打ち手→根拠」を短文で埋める。空欄でも次へ進める設計なら明記。
- 勝ち筋が絞れない：候補を「短期（売上/利益）」「中期（資本効率）」「長期（成長投資）」に分類してから 1〜2 本に絞る。
- ストーリーが一般的：固有情報（顧客/単価/チャネル/競合/規制/人材制約/投資余力）を12問に入れると具体化する。
